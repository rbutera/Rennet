## 4. Harness turns in the WSL locus

- [x] 4.1 Productionised the spike shim: `wsl-launcher.ts` generates a cwd-agnostic `.cmd` launcher (`wslpath -u` translates the SDK-set cwd, then `wsl.exe -d <distro> --cd <distro-cwd> -e <distro-claude> %*`; `-e` byte-verbatim; distro-name + path validated at the trust boundary). `createClaudeHarness({locus})` discovers the distro claude via `wslDiscoveryDeps` and points `pathToClaudeCodeExecutable` at the launcher — capability identical to native (Rule Zero, no reduction). `getClaudeHarness(locus)` memoizes per-distro; the handoff write-turn threads the project locus. Unit-tested (`wsl-launcher.test.ts`, `claude-query.test.ts`). REMAINING (documented): (a) the review-pipeline harness sites still resolve host by default — threading the project locus there needs the UNC project path carried through the review (the captured `repository.root` is distro-native, so it can't re-derive the locus); (b) the SDK-spawns-a-`.cmd` end-to-end + sibling-probe behaviour is a lancelot manual check (no Windows-side node here)
- [ ] 4.2 Codex in WSL — DEFERRED WITHIN CHANGE (honest, per the "record why and continue" latitude). Running `codex exec` in the distro is not a spawn-only change: the executor bakes a HOST scratch dir (`mkdtemp(tmpdir())`) whose `schema.json`/`out.json` a distro-side codex cannot read, and its internal `join(dir,…)` would win32-corrupt distro paths on a Windows host. A correct build needs an executor path refactor (distro scratch via `/mnt/c` mapping OR a distro `/tmp` dir with UNC IO, posix joins, and the session-usage root pointed at the distro `~/.codex/sessions`) plus Windows-node verification I cannot run here. A half-build (spawn-in-distro, host scratch) would BREAK codex on WSL. Left unimplemented so the review honestly degrades to single-Claude on WSL (existing behaviour) rather than shipping a broken codex seat. Design sketch recorded here for the cheap follow-up
- [x] 4.3 Repo watcher: `RepoWatcher.start(root, cb, locus)` uses chokidar polling (`usePolling`, 500ms) for a WSL locus (design decision 7, inotify does not cross 9P/UNC), native event-driven elsewhere; the `.git`/`.rennet` ignore now matches both separator flavours (backslashes on UNC). `startWatching` threads `locusForRepo(root)`. Unit-tested (`repo-watcher.test.ts`)
