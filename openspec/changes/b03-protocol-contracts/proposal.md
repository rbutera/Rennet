# B3 — Protocol contracts: the frozen shapes Track C consumes (#489)

## Why

Track C proper starts only after the protocol shapes it renders are frozen (plan row B3 — "Gate for Track C proper"). Today `packages/protocol` is a flat pile (`index.ts` 3.4k lines, `domain.ts` 2.6k) with no board schema, no `LensBoard` projection, no command-registry metadata, and two temporary lens unions squatting in `app-ui` waiting for this change. B3 restructures the package into contract folders — one public seam each, per engine asset §2 (#489 comment 5431046330) — and declares the new contracts from their decided sources: #462 (host schema), #465 (command registry), #466/#457 (session), #461 (dossier), #486 ripples. Shapes and their tests only; every runtime lands later (B4+, B10).

## What Changes

`packages/protocol/src` gains five contract folders. The root `index.ts` stays the package's single export (`exports: "./src/index.ts"`) and shrinks to a re-export seam over them.

- **`board/`** — the #462 host schema: **13 kinds** in Zod on `@wboard/core`'s authoring kit (Tier A: `finding`, `decision`, `requirement`, `noise_verdict`, `order_step`, `round_outcome`; Tier B: `section`, `prose`, `callout`, `annotation`, `message`, `code_ref`, `review_comment`), shared envelope `author {kind: human|lens-agent|orchestrator, id}`, `severity high|medium|low` (the shipped `FindingSeverity` scale — no vocabulary fork), `code_ref` cites the patchset (code is never copied), closed palette (no `custom`), no protocol relations (references are `element`-typed attributes). Carries the recorded #462 ripples: message quote anchor `{target, quote, offsetHint?}` + ask lifecycle (`staged|dispatched|addressed|retired|detached`), section round-delta stamp (`new|reworked`, absent = carried), `round_outcome` status `addressed|partial|untouched|beyond`. Exports `HostBoardSchema`; `DraftBoardSchema` **derived** by `omit` of the curation-side kinds — never hand-written — with a drift test that fails if derivation breaks; seam `parseDraft(unknown) → Result<DraftBoard, ZodIssue[]>`; `Blemish` and `Violation` shapes (consumed by B8's lint, declared here). Second drift test: Zod → whiteboard wire, through the kit's wire validation. Plus the **`LensBoard` projection shape** (client asset risk 1 — it exists nowhere today; the client must not invent it): lens identity, generation stamp, sections with fold grammar / gists / delta marks, element tree in the 13-kind vocabulary, skipped-hunk data — composed from the `board/` kind schemas, not re-modeled.
- **`commands/`** — the #465 registry: one table keyed by stable command id, rows `{args, output, label, exposure: {ui, commandMenu, agent}, locus: host|client}`, absorbing today's **62** `commandDefinitions` *(cluster-4 amendment: measured count at HEAD; reconciliation 3)* (label = command id per #465's harness-derivable rule; `exposure.agent` true only for the #465 v1 inventory ids that already exist; `locus: "host"` throughout — client-locus rows arrive with their commands). `parseCommandInput`/`parseCommandOutput` move here and stay the validation seam. Sidebar, ⌘K, and the `app_*` tools are three readers of this one table — the readers are B10/Track C business; B3 ships the table.
- **`session/`** — the #466/#457 durable-session shapes: session (durable root; review attaches 1:0..1), claim (target claim, archive-only release), generation (the boards for one review of one patchset, append-then-freeze), round record (`{asks dispatched, worker commit range, minted patchset generation, board generation, report board}` per #462's #486 ripple), harness cursor (`{harness session id, last-assistant-message anchor, turn count}`), thread/anchor (thread id; anchor = code-ref or prose quote; the ask specialization's lifecycle). The existing `session.ts` transport wire layer (#376 — handshake, envelope, frames) moves in as `session/wire.ts`, unchanged: it is the session's wire contract, not a casualty. Shapes only — the state machine is B9.
- **`delta/`** — patchset, stable hunk id, the canonical `CodeRef` (`{patchset id, path, side: base|head, span, symbol?}` — the one definition `board/`'s `code_ref` kind and session anchors reuse), knowledge statement (moved from `domain.ts`), related-context dossier item (#461 §8: `{id, tracker, title, state, bounded body, acceptance criteria?, url, provenance, fetched-at}`, deterministically serializable), **and the patchset span-read command** (client asset risk 2): read a cited span from the captured patchset, never a working tree — registered as a `commands/` row now so Track C freezes against it (dispatch binds it in B4/B10). The RSP decomposition-document validators (`rsp.ts`, `bodies.ts`) re-home here — they validate documents over the offered hunk set.
- **`manifests/`** — ids as data, bytes stay in `prompts`: `LensKind`/`LENS_KINDS` (`design | sequence | decisions | flagged | noise`, moved from `packages/prompts`), prompt ids, `CouncilJobId`/`CouncilJob` (moved from `domain.ts`) plus the plan's new job-id vocabulary (`lens-draft`, `lens-draft-flagged`, `lens-draft-noise`, `board-post-process`, `round-report`, `partition-worker`, `map-verify`, `project-scout`, `related-context-retrieval`) as data. `prompts` re-points to the protocol `LensKind`; `app-ui`'s two temporary lens unions (`canvas/counterpart.ts`, `app/shared.tsx`) are deleted in favor of it.
- **Dependency:** `packages/protocol` gains `@wboard/core@0.1.0-alpha.2` (npm alpha, MIT, `zod ^4.4.3` — matches). Track A5 shipped, so the packet's stub-the-kit contingency is not exercised. No Rennet-package edge changes; `check-boundaries.mjs` and the eslint law are untouched.
- **Docs in the same change:** `protocol-compatibility.md` (registry replaces `commandDefinitions` as the named authority; folder seams), `monorepo-map.md` (protocol row), `review-lenses.md` (lens id vocabulary aligned to `LensKind` — "Spec" → the Design lens, matching `lens-pipeline.md`/#474), plus a grep sweep.

## Reconciliations against main (packet drift, recorded per the dispatch rule)

1. **`@whiteboard/core` → `@wboard/core`.** The whiteboard repo published under the `@wboard` npm scope (`core`/`mcp`/`server`, `0.1.0-alpha.x`). A5 is done (`BUILD-STATUS.json`), so the packet's "stub the kit import behind a local interface" branch is dead.
2. **12 kinds → 13.** The packet's "12 kinds + shared envelope" predates the #486 ripple recorded on #462 (2026-08-26): `round_outcome` is the 13th Tier A kind; the closed palette holds. The engine asset and plan row already say 13. (The client asset says "14-kind vocabulary" twice — a miscount; #462 is the schema authority.)
3. **`commandDefinitions` is 62 rows, not 69**, at `packages/protocol/src/index.ts:2215` — B2 deleted the six `canvas.*` commands and `review.canvases` (69 − 7 = 62). *(Cluster-4 amendment: this line originally said 64 — a count error; the measured table at HEAD has exactly 62 entries, verified mechanically in the cluster-4 registry snapshot test.)*
4. **`LensKind`'s five values.** The temporary `app-ui` union says `spec|sequence|decisions|noise|flagged`; canonical is `packages/prompts` `LENS_KINDS = design|sequence|decisions|flagged|noise` (#464/#474 — the Design lens renders the change's spec artifacts). `spec` is retired for `design`; `docs/developing/concepts/review-lenses.md` still titles the lens "Spec" and is corrected with the same change.
5. **B2 renames already landed:** `instructions` → `prompts`, `delta-account` → `successor-account`. Packet references are read accordingly; `prompts` already carries the `protocol` edge this change leans on.
6. **`session.ts` collision:** the existing file is the #376 transport wire layer, not #466's durable-session model. Both are session contracts; the wire layer moves to `session/wire.ts` unchanged and the #466 shapes join it.
7. **Scope of "restructure" (judgment call, flagged to the dispatcher):** the five folders own their contracts and the root `index.ts` becomes a re-export seam; legacy residue with no folder named by the packet (`domain.ts`'s project/settings/handoff families, `public-schema.ts` R19 projections, the `sha256.ts` util) stays parked at root behind the same seam, migrating with the changes that rework those surfaces (B4–B11). Total physical relocation of ~8k legacy lines that B4–B11 rewrite anyway is churn, not contract work.
8. **New command rows ship unbound.** The span-read row exists in the registry with no dispatch handler until B4/B10 — the wire answers unknown-command meanwhile; Track C builds against `MemoryBridge`. The server's path-coverage guard (`projection.test.ts`) requires the new row's path fields classified repo-relative — a test-table line, not an implementation.
9. **Risk-label provenance.** The packet attributes the LensBoard-projection and span-read risks to "engine asset §2 risk 1/2"; they are actually the CLIENT asset's risks 1–2 (#489 comment 5431046569), which this proposal cites directly. The engine asset's own Top-5 risks are context, not scope: its embeddability bet is retired (published `@wboard/server` is embeddable in-process with pluggable persistence) and its types→protocol unsplittable-diff risk was already executed as B01.
