# C3 — Shell: the three-region frame, sidebar rewrite, top bar, chat-dock slot (#489)

## Why

INVENTORY §1 is 63 `[ws:C3]` claims describing the persistent app frame: a fixed three-region split (sidebar · chat column · main surface), a collapsible sidebar whose tree is a server projection, a 56px session top bar with the trail and the view pill, and a chat column that is never unmounted (R47). None of it exists on the router yet: C1 landed the foundations (data seam, store, #480 router, `MemoryBridge`) with a deliberately bare interim layout, and the product still mounts the LEGACY `app/shell.tsx` (`RennetApp`, ~1,087 lines, `Surface`-stack navigation) because C1 deferred its cutover (task 4.5). The spike's sidebar is autopsy S5 — `app-sidebar.tsx`, 787 lines behind a 17-prop callback interface, every mutation prop-drilled from the shell. C3 builds the real frame on C1's seams and C2's primitives, rewrites the sidebar from projection with zero props, and performs the deferred cutover so the router app IS the running client — a frame that never mounts can satisfy none of its 63 claims.

## What Changes

All in `packages/app-ui`, on C1's seams (`data/`, `store/`, `routes/`) and C2's primitives (`Collapse`, `Resizable`, `ToggleGroup`, `ContextMenu`, `Kbd`). **Zero new dependencies.**

- **Frame — `routes/layout.tsx` becomes the real three-region split.** Fixed full-viewport, no page scroll on the frame; region order sidebar · chat dock · main surface (the dock sits between sidebar and outlet, per §1). The chat-dock slot keeps C1's guarantees: the SAME always-mounted element outside the outlet (`data-testid="chat-dock-slot"` — the risk-4 test keeps passing), now hidden by animating its wrapper width to 0 **and marking it `inert`** whenever the chat is closed or the route is a takeover (settings, new chat, archived, map, indexing); it shows only on session routes. The divider between dock and surface is C2's `Resizable` with the consumer-owned constants C2's reconciliation 3 pushed out of the kit: chat min 320, surface min 400, max = whatever the container leaves, double-click reset 420; dragging suppresses the width transition, re-armed 200ms after the drag stops. Dock internals stay empty — C7 fills them.
- **Top bar — `shell/top-bar.tsx`, the 56px session-surface header** (R51), rendered by the frame on session routes. Three-column grid: left slot (back arrow exactly when `?view` is not the board, chat-expand control when the chat is collapsed, then the two-line trail), a centered **lens-switcher slot** (C5 fills it), right slot the **History · Map · Diff pill** — C2 `ToggleGroup` over `?view` (`rounds`/`map`/`diff`), selection DERIVED from the URL, toggling navigates through `viewToggle()` (replace semantics), deselect = board. The trail (`shell/trail.tsx`) is session title over target-icon + `project › target`, "· needs you" as words never a pill (R52); C7's chat-pane header reuses the same component later.
- **Sidebar — a rewrite, not a port** (R35): `shell/sidebar/` replacing the S5 anti-pattern. The component takes **no props**. Tree data comes from the server projection through `useCommand`/`useCommandStream` (via one `shell/sidebar-data.ts` module — reconciliation 2); every mutation (session rename/pin/archive, project rename/remove) is a command through `useMutation`; the active-session highlight is DERIVED from the route (wouter hooks + the slug helper), never stored; fold state lives in the `ui` slice (`sidebarFolds`/`toggleFold`), folds animate through C2 `Collapse`. Structure per §1: 256px panel ↔ 48px rail on one width-animated element, both carrying the collapse control; the real lockup (vector artwork from `brand/exports/logo/svg/`, scheme-swapped, never a font); action block ordered Search (`⌘P` hint via `Kbd`, opens the command menu by setting `ui.commandMenuOpen`) → New Chat (searchable project picker on the kit's `Command`/`Popover`) → Add Project → Add Environment; host group headers with monitor/server glyphs, no "PROJECTS" label, no IPs, no "daemon"; project rows (chevron + glyph + name + non-archived count, spinner + "indexing" while processing, force-expand the active project, ghost New Chat row); session rows (target icon leading — `target-badge` JSX ported through the fence — accent icon for needs-you, green tick for reviewed, pin glyph, verdigris unread dot never on the active row, muted relative-time second line); Pinned section only when non-empty; right-click menus on C2 `ContextMenu` (project: View Context Map / Rename / Project Settings / Remove project…; session: Pin/Unpin / Rename / Archive); inline rename (Enter commits, Escape cancels, emptied name falls back); Remove project… the destructive confirmation naming the session count and stating the repo on disk is untouched (`projects.remove` — a real command today); footer: Archived entry with count exactly when >0, Update control (real `useUpdateReady`/`applyUpdate` wiring, present when an update is actually ready), Help popover (Documentation, Keyboard Shortcuts → `/settings/keybindings`, Replay Tour, Report an Issue; no "Contact support"), Settings. Archiving or removing what you are standing in navigates away instead of stranding you.
- **Cutover (C1's deferred 4.5).** Both entry points (`apps/desktop/src/renderer/index.tsx`, `apps/desktop/src/browser/entry.tsx`) mount `RennetRouterApp` (inside `ConnectionHost`, with their C1-selected histories) instead of the legacy `RennetApp`. The legacy shell and what the swap orphans are DELETED — `app/shell.tsx`, `components/breadcrumb.tsx`, the legacy palette (`command-palette.tsx`, `command/commands.ts`), `nav/history.ts`, `ChromeMenu` — and their lint-quarantine lines drained. Reconciliation 4 records the consequences.
- **Theme gap, not hexes:** the verdigris unread-dot register (R53) and the update-control fill have no theme token; they are added to `packages/theme` (fence rule — a missing token is a theme gap to fill, never a bracket to inline).
