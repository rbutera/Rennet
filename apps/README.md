# Applications

Production applications live here. `desktop` packages the Electron client and local daemon. `mobile` is the in-progress native client, tracked by [#383](https://github.com/rbutera/rennet/issues/383). `docs` renders the canonical root documentation. `marketing` builds the public site. The [dependency standard](../docs/developing/reference/dependency-standard.md) defines framework, packaging, UI, and release choices.
