Rennet is a local-first code review harness. It reads a diff, routes the change
through one or more models, produces findings, and lets you sign off — all on
your own machine.

This area is for **using** Rennet. If you are building Rennet itself, switch to
[Developing Rennet](/developing/) in the sidebar.

## Where to start

- **[Getting started](/using/guide/getting-started/)** — the shape of a review, end to end.
- **[User journey](/using/guide/user-journey/)** — a real walk through a review session.
- **[Product and vision](/using/concepts/product-and-vision/)** — what Rennet is for, and what it deliberately is not.

## What you can do with Rennet

- Digest a diff or a pull request into something you can actually read.
- Run a review across a configured set of models.
- Read findings grouped by the file and the flow they touch.
- Sign the review — record your dispositions and produce the paper.
