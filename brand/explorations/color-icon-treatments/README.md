# Colour icon treatment explorations

These are three visual-treatment references for the colour-gradient application icon. Compare them in `comparison.png`:

1. `01-opalescent-glass.png` — translucent milky glass, spectral edge, cool and technical.
2. `02-champagne-chrome.png` — warm liquid metal, restrained and premium.
3. `03-coral-signal.png` — coral-to-amber emission, playful and high contrast.

These PNGs explore material, light, and colour only. Image generation regularised some fragment shapes, so they are not production masters. Once a treatment is selected, apply it deterministically to the exact narrowed mark in `../../sources/mark-master.svg`; do not trace or ship the generated geometry.
