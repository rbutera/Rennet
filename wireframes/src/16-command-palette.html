Command palette: the keyboard spine

Cross-cutting
command-K · every action, named plus a Navigate group on every screen

Command-K. Every action is a named, remappable command — and in v4.0 the palette is also the keyboard spine of navigation. A Navigate group rides every screen: Go to project…, Open review…, Back / Forward, Go to Draft / Paper, Open Settings. On an empty query it shows your recent locations first, so returning to a place is one keystroke. The retired claims lens is gone from the offered set.

Designer notes  /  what to weigh in on
1
The keyboard spine. One overlay, one search field, every action and every destination reachable by name. As an overlay it never moves the crumb or the history — running Back from here is what moves them.
2
A Navigate group everywhere. Present on every screen: Go to project… (fuzzy over projects), Open review… (fuzzy over the current project’s rows), Back / Forward, Go to Draft / Paper, Open Settings. The legacy “Review directly” door lives here too — palette-only, no drawn button.
3
Recent locations first. With an empty query the palette leads with where you have just been, so returning to review B after glancing at A is a single keystroke — the cheapness that lets one review evict another.
4
Named and remappable. Each command carries a default key hint you can rebind. No retired destinations: the resteer-era claims lens is not offered.
