Two names, worn

Digestif and Rennet on the same product: the review-surface masthead, then a minimal landing hero. Each name gets its one best wordmark call, not a grid of options. Judge by eye.

Wordmark calls, stated: Digestif is set lowercase in New York semibold with one amber tittle and a level-line glyph (a measure, not a bottle); the name belongs to the reading-room register, so the mark borrows the narrative voice. Rennet is set capitalised in SF semibold with a cleave glyph (one round split into a solid half and an open half); it is a working agent's name, so the mark takes the tool voice and its hero earns exactly one flourish, the separation rule.
