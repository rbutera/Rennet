Claude Code 14:36

It follows the plan: docs/plan.md names "limiter outage must never become API outage" as a hard requirement. Failing closed turns every Redis blip into a full 5xx storm for all 4,112 orgs, which is a worse incident than a window of unmetered traffic.

The window is also observable: rate.store_error counts every pass-through, so an outage is visible the moment it starts.
