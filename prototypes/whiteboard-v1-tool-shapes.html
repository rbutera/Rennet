Whiteboard v1 — the agent-facing surface

Watch the Tool console: every button shows the exact JSON an agent would send and get back. Two actors: navi (agent, gold) and rai (you, blue). Click any element on the board to select it as rai — that selection lands in the same log the agent reads. No layer is off-limits to anyone.
