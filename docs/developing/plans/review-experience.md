This work is planned in [#904](https://github.com/rbutera/rennet/issues/904).
The issue owns the accepted requirements and implementation status.

The review should remain readable while its generation runs. Activity belongs
in the review header, lens controls and sidebar, with detailed seat activity
available on demand. Folded sections should reveal their contents, and code
references should open real diffs without implying a reviewer selection.

The independent implementation tickets are
[generation and background activity](https://github.com/rbutera/rennet/issues/905),
[immutable code evidence](https://github.com/rbutera/rennet/issues/906), and
[section previews and element structure](https://github.com/rbutera/rennet/issues/907).
Their combined acceptance uses the existing launched-app review journey,
followed by the repository checks and a standards/specification review.
